# Mineral Prospectors Sierra Leone — website preview

A plain **HTML5, CSS and JavaScript** copy of the Mineral Prospectors Sierra Leone website, for viewing online.

**View it:** https://sha-drach.github.io/mineral-prospectors-website/

## Pages

`index.html` (home), `about.html`, `services.html`, `minerals.html`, `projects.html`, `gallery.html`, `contact.html`

## Notes

- No server or database is needed: open `index.html` in a browser, or host the folder anywhere.
- The contact form opens WhatsApp with the visitor's message filled in, because there is no server to receive it.
- This copy has no admin panel. Content is managed in the full PHP version of the site, and this copy is rebuilt from it with `php tools/export-static.php`.
- Scroll animations use [AOS](https://michalsnik.github.io/aos/), loaded from a CDN.
